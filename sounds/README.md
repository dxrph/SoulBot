# Suoni della soundboard

Metti qui i file `.mp3` o `.ogg` (massimo 512 KB, clip brevi di circa 5 secondi) e fai il push.
Poi su Discord il proprietario del server usa `/carica-suoni` senza allegato: il bot carica
tutti i file di questa cartella che non sono già nella soundboard.

- Il nome del suono è il nome del file senza estensione (2-32 caratteri), es. `gojo-ryoiki-tenkai.mp3`.
- Slot disponibili: 36 al livello boost 2.
- In alternativa: `/carica-suoni file:<allegato> nome:<nome>` per caricarne uno solo senza push.
